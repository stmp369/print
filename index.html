const firebaseConfig = {
  apiKey: "...",
  authDomain: "...",
  projectId: "...",
  storageBucket: "...",
  messagingSenderId: "...",
  appId: "..."
};

Also make sure Firestore Database is created in your project (any region), and rules allow read/write for this app's use case.
